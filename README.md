## ✨ Features

- **🏠 Home** - Interactive hero section with dynamic status
- **📝 Resume** - Experience timeline and certifications
- **🛠️ Skills** - Technology showcase with visual grid
- **💼 Portfolio** - Project gallery with live demos
- **📰 Blog** - MDX-powered articles with syntax highlighting
- **🧠 AI Quiz** - Multi-category knowledge tests with leaderboards
- **🤖 AI Interview** - Interactive hiring simulation with Google Gemini
- **⚔️ AI Battle Mode** - Real-time multiplayer quiz battles
- **📱 Responsive** - Optimized for all devices
- **🌓 Dark Mode** - System-aware theme switching

## 🛠️ Tech Stack

- **Framework:** Next.js 15 with App Router
- **Language:** TypeScript
- **Styling:** TailwindCSS 4
- **Database:** Supabase with real-time subscriptions
- **AI:** Google Gemini
- **Animations:** Framer Motion
- **Deployment:** Vercel

## 🚀 Quick Start

1. **Clone & Install**

```bash
git clone https://github.com/ihsaninh/my-portofolio-next.git
cd my-portofolio-next
bun install
```

2. **Environment Setup**

```bash
cp .env.example .env.local
```

Add your credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
GOOGLE_GENERATIVE_AI_API_KEY=your_gemini_api_key
```

3. **Run Development**

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📝 Available Scripts

```bash
bun dev          # Start development server
```

## 🎨 Customization

- **Content:** Update files in `src/data/`
- **Styling:** Modify `tailwind.config.js`
- **Components:** Edit files in `src/components/`
- **Blog Posts:** Add MDX files to blog directory
